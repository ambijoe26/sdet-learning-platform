# Sr. SDET Interview Preparation Platform

A comprehensive, interactive React-based learning platform designed to prepare you for Senior SDET (Software Development Engineer in Test) interviews at top-tier companies.

## 🎯 Overview

This platform provides a complete 5-month curriculum covering:
- **Month 1**: Java Mastery & Selenium Foundation
- **Month 2**: TestNG, Cucumber & BDD Framework
- **Month 3**: API Testing & CI/CD Integration
- **Month 4**: Advanced Topics & System Design
- **Month 5**: Interview Mastery & Real-World Scenarios

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ installed
- npm or yarn package manager

### Installation

```bash
# Navigate to project directory
cd sdet-learning-platform

# Install dependencies
npm install

# Start development server
npm start
```

The application will open in your default browser at `http://localhost:3000`

### Build for Production

```bash
npm run build
```
